# Security Policy

## Reporting a Vulnerability
Please **do not** open a public GitHub issue for security vulnerabilities (such as WebPortal authentication bypasses, sandbox escapes, OTA signature/verification flaws, or credential exposure).

Instead, report vulnerabilities privately using **GitHub Security Advisories** (**Security → Advisories → Report a vulnerability**) on this repository.

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce (and PinhOS version / build from `version.json`).
- Any suggested mitigation or patch, if available.
