# PinhOS `v1.0.0-alpha.4.1` — Stability, Security & Watchdog Hardening (Pre-Release)

> **Milestone:** Phase 4.1 Stability & Security Bugfix Release  
> **Target Hardware:** ClockworkPi PicoCalc (Raspberry Pi Pico 2W / RP2350A + CYW43439)  
> **Tag:** `v1.0.0-alpha.4.1` (`3debd80`)

## Highlights
- **WebPortal Security Foundation (`#15`, `#17`, `#18`):** Added `X-PinhOS-Token` authentication on mutating endpoints, strict `Origin` header check, write-path allowlist, `/api/run` `409 Conflict` guard + `/api/run/status`, and WebPortal `pause()`/`resume()` around radio-intensive tools.
- **RP2350 Hardware Watchdog (`#14`):** Introduced `enable_wdt()` / `feed_wdt()` and `AppContext.yield_()` cooperative feeds to recover automatically from hard freezes.
- **SRAM & Heap Safety (`#5`, `#6`, `#12`, `#16`):** Added `core/memutil.py` contiguous-block metric (`largest_free`), fixed `16 KB` `MemoryError` in `tools/files.py:read_text_preview`, added contiguous-heap guard in `tools/editor.py`, unified `_exec_sandboxed`, enforced OS SRAM reserve, and narrowed sandbox module purging.
- **Non-Blocking Boot Wi-Fi & NTP (`#1`, `#8`, `#9`):** Moved boot Wi-Fi auto-connect to a non-blocking state machine excluded from the 5s Boot Guard, pumped the CYW43439 RX FIFO during UDP SNTP and HTTP Date fallback, and added config migration/pruning + `wifi_country`.
- **Cooperative Screenshots & Forensics (`#19`, `#20`, `#22`):** Added cooperative `screenshot_iter`, rolling `last.bmp`, keep-5 screenshot pruning, boot `gc.threshold`, persisted `boot_id` + `ticks_ms` offset + `~UNSYNCED` clock marker, and single-source-of-truth OTA repo/branch in `version.json` (`#21`).
- **Self-Test & Tooling (`#2`, `#10`, `#11`):** Added live per-gate Self-Test Runner progress screen, on-demand Stress Gates 13–14 (`tests/selftest_stress.py`), `apps/wifi_spectrum.py`, and 4× faster `picocalc.ps1 screenshot`.

> **Note:** Superseded by **`v1.0.0-alpha.4.2`**, which completes the full Phase 4.x stability audit close-out (read-side WebPortal auth, standalone WDT tool-loop fixes, deep stress suite, and release stamping).
