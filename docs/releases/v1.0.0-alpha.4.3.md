# PinhOS `v1.0.0-alpha.4.3` — Menu Watchdog Hotfix (Pre-Release)

> **Milestone:** Phase 4.x Final Hotfix Baseline (Ready for Phase 5)  
> **Target Hardware:** ClockworkPi PicoCalc (Raspberry Pi Pico 2W / RP2350A + CYW43439)  
> **Tag:** `v1.0.0-alpha.4.3` | **Build:** `20261124.3`  
> **Hardware Verification:** Standalone battery menu/dialog idle test PASS (zero 8s WDT reboots)

## What's Fixed
- **Menu & Dialog Watchdog Feeding (`boards/picocalc.py`, `ui/menu.py`, PR #49):**
  - Updated `boards/picocalc.py:poll_key()` to feed `sys.modules["__pinhos_wdt__"]` instead of read-only `builtins._pinhos_wdt`, ensuring every menu, dialog, log viewer, tool, and app loop keeps the RP2350 hardware WDT fed while still recovering from real freezes.
  - Updated `ui/menu.py` (`_idle_wait()` and `open_menu_tree()`) to feed `__pinhos_wdt__` directly and resolve both `main` and `_pinhos_main` when stepping WebPortal inside menus on standalone boots.
- **Phase 5 Tracking (`ROADMAP.md`):**
  - Added Phase 5.4 WDT reset & watchdog log viewer task (`#48`) alongside Phase 5.1 configurable boot/periodic NTP sync (`#47`).
