# PinhOS `v1.0.0-alpha.4.4` — Watchdog Diagnostics (`wdt.log`), Wi-Fi WDT Feed & Recovery Notice (Pre-Release)

> **Milestone:** Phase 4.x Watchdog UX & Stability Polish  
> **Target Hardware:** ClockworkPi PicoCalc (Raspberry Pi Pico 2W / RP2350A + CYW43439)  
> **Tag:** `v1.0.0-alpha.4.4` | **Build:** `20261124.4`

## Highlights
- **Wi-Fi Connect & NTP Watchdog Feed (`net/wifi.py`):** Fed `sys.modules["__pinhos_wdt__"]` inside `_sleep_ms()` so blocking Wi-Fi connects (up to 24s), radio bounces, DHCP waits, and NTP syncs never trip the 8s RP2350 hardware watchdog.
- **Dedicated Watchdog Log in Logs Menu (`#48`, `core/logger.py`, `ui/_log_view.py`):**
  - Added `/sd/pinhos/logs/wdt.log` recording every WDT arm event and `machine.WDT_RESET` recovery (detected even when the previous breadcrumb was `IDLE`).
  - Exposed **`wdt.log`** directly in the on-device `CTRL+L` / **System > Logs** picker with warning color highlights.
- **Friendly Watchdog Recovery Dialog (`main.py`):**
  - When recovering from a hardware WDT reset, PinhOS now displays a **`WATCHDOG RESET RECOVERED`** popup showing the last operation, free SRAM before reset, and a pointer to `[CTRL+L] -> wdt.log` instead of silently rebooting to Desktop.
