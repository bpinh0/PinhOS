> **Hardware Verification:** **12/12 Self-Test Gates PASS** + **Deep Stress Suite PASS** (Gates 13–14 + 7-menu walk) + **Standalone Battery WDT Verified** on PicoCalc (`COM4`)

## Security & WebPortal Hardening
- **Full `/api/*` Read & Write Auth (`#23`, PR #31):** Removed the static `"pinhos01"` fallback in favor of a fail-closed 16-hex `os.urandom(8)` token generated per session and enforced `X-PinhOS-Token` on all `/api/*` reads and writes.
- **Sensitive-File Denylist & Lockout (`#23`, PR #31):** Blocked remote access (`403`) to `wifi.json`, `.swap/`, `logs/breadcrumb.json`, `boot_state.json`, and `rtc_state.json`; added a 5-failure `429` lockout (`30s`) and authenticated Blob URLs in `web/static/app.js`.
- **On-Device Token UX (`#23`, PR #31):** Added uncropped `WEBPORTAL IDE ACTIVE` URL & Token popup on enable, `6 → WebPortal URL & Token` dialog in `ui/menu.py`, and `WEB ON [6:KEY]` status indicator on Desktop Home.
- **WebPortal Autostart Fix (`#29`, PR #37):** Moved `wifi_bg_pending` and `webportal_autostart` into idempotent `_init_interactive_services()` on `ui_loop()` entry so both cold boots and `picocalc.ps1 upload_and_start` honor `webportal_autostart=True` (covered by Gate 12 regression check).

## Watchdog & Standalone Stability
- **RP2350 Watchdog Fixes (`#28`, PR #32, #40, #41, #42, #43):**
  - Fixed read-only MicroPython `builtins` dropping the `machine.WDT` handle — now shared via `sys.modules["__pinhos_wdt__"]` + module global `_WDT_OBJ`.
  - Fed WDT unconditionally in `ui_loop()` (fixing 8s reboots when WebPortal was active) and wrapped `board.poll_key` inside `core/sandbox.py` so every sandboxed tool (`shell`, `files`, `editor`, `net_tools`, `uart_term`, `sysmon`) keeps the WDT fed automatically.
  - Added WDT feeds in `_TrackedHandle` file I/O (`read`/`readline`/`write`), capped `net/sync.py` socket timeouts to `<= 4s` with per-chunk feeds, added `ctx.yield_(step_web=False)` in `apps/wifi_spectrum.py`, gated WDT arming to standalone boots, and added a hardware `Timer` REPL keep-alive on serial `Ctrl+C` so `COM4` tooling works seamlessly after a standalone boot.

## Observability, Heap Telemetry & UX
- **Structured Logging (`#24`, PR #35):** Fixed per-line `boot_id` SD churn by caching `_BOOT_ID` and `_BOOT_T0_MS` in module globals; added boot-relative `+ms`, HTTP status code + client IP + denied-request logging in `web.log`, and Wi-Fi elapsed-ms / NTP result logging.
- **96 KB Contiguous-Heap Telemetry (`#13`, `#26`, PR #33, #36):** Raised `core/memutil.py:largest_free(cap=98304)` default cap from 32 KB → 96 KB, logged post-GC `free` + `blk` on WebPortal `START` and `HEAP[BOOT_OK|WEB_START|IDLE_DESKTOP|FIRST_TOOL]` stages, and added `docs/runbooks/issue13_heap_timeline.md`.
- **Wi-Fi Country Code & Version Fallback (`#27`, PR #39, #44):** Added ISO-3166 alpha-2 `Wi-Fi Country Code` prompt/validation in `Settings > Wi-Fi & Connectivity` (rejecting `"XX"`), replaced stale `3.1` version fallbacks, and added `_ensure_manifest()` lazy loading.

## Deep Stress Testing & Release Engineering
